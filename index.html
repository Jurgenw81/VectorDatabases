How it works

Files become vectors.
Search becomes similarity.

Instead of searching filenames, Local Vector Search turns images and text into numerical representations of their meaning.

Your files Images and documents stored locally.

Features

More useful than filenames.

Search based on what a file contains or means instead of trying to remember what you named it.

⌕

Text → Image

Search your photo library with queries such as “red sports car” or “sunset over mountains.”

◎

Image → Image

Give the search engine an existing image and retrieve visually and semantically similar files.

≡

Semantic Text Search

Find notes and documents based on their meaning rather than requiring exact keyword matches.

⚡

Fast Vector Search

FAISS performs efficient nearest-neighbor searches across your generated embeddings.

⌂

Local First

Your searchable index and original files remain on your own computer.

Simple Python

Get started

Three commands to start searching.

Install the Python dependencies, index a directory, then search it using normal language.

01
Install dependencies 
pip install sentence-transformers faiss-cpu pillow numpy tqdm
02
Index your images 
python local_search.py index-images ~/Pictures
03
Search 
python local_search.py search-images "sunset over mountains"
Example

The filename doesn't matter.

CLIP understands relationships between text and visual content. Your image can have a meaningless camera filename and still be found.

terminal — local-vector-search
$ python local_search.py search-images "dog playing in snow"

Documents

It works for text too.

Documents are split into chunks and embedded using a text embedding model. FAISS then retrieves chunks that are semantically related to your question.

01
Index documents 
python local_search.py index-text ~/Documents
02
Search documents 
python local_search.py search-text "where did I write about database performance?"
