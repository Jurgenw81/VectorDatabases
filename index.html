How it works

Turn files into vectors. Search the vectors.

Instead of relying on filenames, the Python application represents your images and documents as numerical embeddings. Similar meanings end up closer together in vector space.

01
Your files

Images and documents stored on your computer.

→
02
Embeddings

CLIP or Sentence Transformers converts content to vectors.

→
03
FAISS

The vectors are stored in a searchable local index.

→
04
Results

FAISS returns vectors closest to your query vector.

Search modes

Images, similar images and documents.

T→I

Text → Image

Search photos with descriptions like "dog playing in snow" even when the words never appear in the filename.

I→I

Image → Image

Give CLIP another image and retrieve visually or semantically related images from your index.

T→T

Text → Text

Search notes and documents based on their meaning rather than requiring exact keyword matches.

DB

FAISS index

The actual search

This is where CLIP really runs.

The browser page explains the project. The actual semantic search happens in Python. The query is embedded with CLIP and passed to FAISS.

terminal
$ python local_search.py search-images "dog playing in snow" # 1. CLIP converts the text into an embedding query_vector = model.encode(query) # 2. Normalize the query vector query_vector = normalize(query_vector) # 3. FAISS searches for nearest image embeddings scores, ids = index.search(query_vector, limit) # 4. The matching paths from YOUR library are returned

      Models
    



    

      Two embedding models.
    



    



      


        

          Image + text
        


        

          sentence-transformers/clip-ViT-B-32
        


        

          Used for images. CLIP places images and text in a
          compatible embedding space, enabling both text-to-image
          and image-to-image retrieval.
        


      




      


        

          Text
        


        

          sentence-transformers/all-MiniLM-L6-v2
        


        

          Used for document chunks. Queries and document text
          are embedded into the same semantic vector space.
        


      



    


  












  


    

      Vector database
    



    

      FAISS stores the embeddings.
    



    


      The script L2-normalizes vectors and stores them in
      IndexFlatIP. With normalized vectors,
      inner-product ranking corresponds to cosine-similarity
      ranking.

    




    


      


        

          
          
          
        


        

          local_search.py
        


      



      
# Normalize embeddings
embeddings = normalize(embeddings)

# Create the FAISS index
dimension = embeddings.shape[1]

index = faiss.IndexFlatIP(dimension)

# Store vectors
index.add(embeddings)

# Save the database
faiss.write_index(index, ".local_vector_db/images.faiss")


    


  












  


    


      

        Local first
      


      

        Your indexed files stay on your machine.
      


      


        The Python application reads files from your computer
        and stores the generated FAISS indexes and metadata
        locally. The embedding models must initially be
        downloaded, but normal indexing and searching does not
        require sending your personal image or document
        collection to a hosted vector database.
