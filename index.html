Search your files by meaning.

The idea

Stop trying to remember filenames.

Normal file search is great when you know a filename or exact keyword. Semantic search solves a different problem: finding something based on what it means.

Traditional search
IMG_4837
You need to know something about the filename first.
Semantic search
dog playing in snow
CLIP compares the meaning of your text query with the visual content represented by the indexed image embeddings.
Architecture

From files to searchable vectors.

Indexing and searching use the same embedding space. FAISS stores those vectors and retrieves the nearest matches to a query vector.

01
Files

Images or text documents on your computer.

→
02
Embeddings

The model converts content into numerical vectors.

→
03
FAISS

The normalized vectors are stored in a search index.

→
04
Nearest matches

Search returns the vectors closest to your query.

What it does

Three kinds of semantic search.

T→I

Text to image

Type a natural-language description and retrieve images whose CLIP embeddings are closest to the query.

I→I

Image to image

Embed an image and use its vector to retrieve similar images from the same FAISS index.

T→T

Text to text

Split documents into chunks, embed them, and search for passages related to your query.

DB

Vector index

FAISS handles nearest-neighbor search across the vectors generated by the embedding models.

↳

Recursive indexing

Point the Python program at a directory and it recursively discovers supported files.

PC

Local index

The generated FAISS indexes and metadata files are stored on your own machine.

                    Image + text
                


                

                    sentence-transformers/clip-ViT-B-32
                


                

                    Used for the image index. CLIP can represent
                    both images and text in a compatible embedding
                    space, which enables text-to-image and
                    image-to-image retrieval.
                


            



            


                

                    Text
                


                

                    sentence-transformers/all-MiniLM-L6-v2
                


                

                    Used for document search. Text chunks and
                    queries are embedded into the same vector
                    space and compared for semantic similarity.
                


            


        


    












    


        

            Vector similarity
        


        

            Why IndexFlatIP?
        


        


            Before vectors are stored or searched, the Python
            implementation L2-normalizes them. With normalized
            vectors, inner-product ranking corresponds to cosine
            similarity ranking.

        



        


            


                

                    
                    
                    
                


                

                    Python
                


            



            


                

                    
                        # Normalize the vectors
                    
                


                

                    faiss.normalize_L2(embeddings)
                


                


                

                    
                        # Exact inner-product index
                    
                


                

                    index = faiss.IndexFlatIP(dimension)
                


                

                    index.add(embeddings)
                


                


                

                    
                        # Retrieve nearest vectors
                    
                


                

                    scores, ids = index.search(query_vector, limit)

                Local first
            


            

                Your search index stays on your machine.
            


            

                The Python application reads local files and stores
                its FAISS indexes and metadata locally. The embedding
                models must be downloaded before first use, but the
                normal indexing and search flow does not require
                uploading your image or document collection to a
                hosted search database.
