How it works

Files become vectors. Queries become vectors.

Semantic search compares numerical representations of meaning rather than relying only on filenames or exact keywords.

01
Your files

Images and text documents stored on your computer.

→
02
Embeddings

CLIP or Sentence Transformers converts content into vectors.

→
03
FAISS

Normalized vectors are stored in a local search index.

→
04
Results

The nearest vectors are mapped back to your original files.

Search modes

Search more than filenames.

T→I

Text → Image

Search for an image using a natural-language description such as "dog playing in snow".

I→I

Image → Image

Use an existing photograph as the query and retrieve semantically related images.

T→T

Text → Text

Search document chunks based on their meaning rather than exact keyword matches.

DB

FAISS

Store vectors locally and perform nearest-neighbor searches across your index.

↳

Recursive indexing

Point the program at a directory and recursively discover supported files.

PC

Local first

The FAISS indexes and metadata stay on your own computer.

The real search

The Python program does the semantic work.

The website above demonstrates the interaction. In the real application, CLIP creates the query embedding and FAISS retrieves the nearest image vectors.

terminal
$ python local_search.py search-images "dog playing in snow" # The text query is converted into a CLIP vector. query_vector = model.encode(query) # Normalize it before searching. faiss.normalize_L2(query_vector) # Retrieve nearest image embeddings. scores, ids = index.search(query_vector, limit) # Map the result IDs back to real files on disk.

            Embedding models
        



        

            Different models for different data.
        




        


            


                

                    Images + text
                


                

                    sentence-transformers/clip-ViT-B-32
                


                

                    CLIP represents images and text in a compatible
                    embedding space. That is what makes natural-language
                    image retrieval possible.
                


            



            


                

                    Documents
                


                

                    sentence-transformers/all-MiniLM-L6-v2
                


                

                    Document chunks and text queries are converted
                    into semantic embeddings and compared in the
                    same vector space.
                


            


        


    












    


        

            Vector search
        



        

            Why FAISS IndexFlatIP?
        



        


            The embeddings are L2-normalized before indexing.
            With normalized vectors, inner-product ranking gives
            the same ranking as cosine similarity.

        




        


            


                


                    
                    
                    

                


                

                    local_search.py
                


            



            
# Normalize vectors
faiss.normalize_L2(embeddings)

# Create an exact inner-product index
dimension = embeddings.shape[1]
index = faiss.IndexFlatIP(dimension)

# Add vectors
index.add(embeddings)

# Save index
faiss.write_index(index, ".local_vector_db/images.faiss")
